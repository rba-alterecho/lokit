## O que não está aqui

O acordo parassocial, o modelo financeiro e o histórico comercial vivem fora
deste repositório (Google Docs partilhado pelos sócios). São documentos com
dados de pessoas singulares e com informação comercial sensível, e quem tem
acesso a um repositório passa a ter acesso também ao histórico dele, que não se
apaga com um commit.

Antes de dar acesso a este repositório a alguém de fora da sociedade, vale a
pena reler esta pasta a pensar nessa pessoa.
